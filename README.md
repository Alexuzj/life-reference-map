# 参照 CANZHAO

**迷茫的时候，先别急着找答案。找几个走过类似道路的人。**

[English](README_EN.md) · [复制中文 Prompt](prompt-cn.md) · [Copy the English prompt](prompt-en.md)

## 这是什么？

我一直对很多事情感兴趣：文化艺术、餐饮、美食美酒、城市和审美。

但当我认真思考职业和人生方向时，兴趣多反而成了困惑：这些事情能不能连起来？有没有人也喜欢不同领域，并且真的把它们变成了一条清晰的人生道路？

我发现，我缺的不是更多建议，而是一个可以参考的人。

于是有了「参照」。它是一段可以直接复制给 ChatGPT、Claude、DeepSeek 等 AI 的对话提示词（Prompt）。AI 会用几个问题了解你的处境，整理出一份暂时的参照画像——也就是你想怎样工作、生活，以及愿意为此付出什么——再帮你找到 3–5 位值得研究的候选人物。

这些人不是标准答案，也不一定是最成功的人。他们只是几个锚点，让你看看别人如何成长、选择、犯错，又如何把不同兴趣组织成一条路。

## 它适合谁？

- 正在考虑离职或转行，却不知道下一步往哪里走
- 兴趣很多，不想被一个职业标签框住
- 对未来焦虑，身边又找不到可以参考的人
- 想认真探索方向，但不想再做一套性格测试

## 怎么使用？

1. 打开 [中文 Prompt](prompt-cn.md) 并复制全文。
2. 粘贴到你常用的 AI。
3. 跟着它的问题回答，尽量讲真实经历，不要只讲理想中的自己。
4. 最后保留 2–3 位真正让你有感觉、愿意继续研究的人。

整个过程大约需要 **15–20 分钟**。

## 使用前，请记住

「参照」不会替你决定人生，也不能保证找到所谓“正确的人”。它提供的是一组值得验证的线索。

真正有用的部分，不是得到一张漂亮的名单，而是在判断“这个人为什么吸引我”的过程中，更清楚地看见自己。

AI 也可能出错。涉及人物经历、书籍、访谈和链接时，请检查来源。Prompt 已要求 AI 标注未经核验的信息，但不要把它的回答当成事实本身。

## 为什么叫「参照」？

因为这些人不是偶像，也不是模板。

你不需要复制他们的人生。你只是借他们走过的路，看见原来还有这样的可能。
